Escopo do desafio

Escopo do desafio

O enunciado do desafio, como foi recebido: o domínio da alçada, o que a API e a persistência precisam sustentar, e o que as três telas precisam mostrar.

Regra de alçada
O domínio: faixas por obra, cadeia ordenada de aprovadores e o efeito de uma rejeição.
Backend e persistência
API, entidades mínimas, regras de cálculo, estados do pedido e validações de servidor.
Front-end
As três telas, estados obrigatórios, responsividade e validações de interface.
O contrato, as rotas, o formato dos dados e o layout das telas são livres. O que está fixo é o comportamento descrito nestas páginas.
